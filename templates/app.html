      グループ

      Vault に入れた人は、その Vault のパスワードを復号して見られます。 誰がいつ何を見たかは監査ログに残ります。 グループで入れた場合は、あとからグループに入った人も見られるようになります（グループの中身は管理者が決めます）。 グループに付けられるのは viewer と editor だけで、owner は人にだけ付けられます。
      ゴミ箱

        点検
        期限切れ・期限間近 （30日以内）
        弱い・使い回し・古いパスワード

        編集できる（editor 以上の）Vault のパスワードをサーバーで復号して調べます。値は画面に出ず、比べた結果も保存しません。 点検したことは Vault ごとに監査ログに残ります。

        自動化トークン

        cron やデプロイから PASSPORT_TOKEN=... passport read "Vault/アイテム" で秘密を読むためのトークンです。 決めた Vault を読むことしかできず、期限は必須（最長1年）です。発行できるのは、対象の Vault すべての owner です。 発行した人が対象の Vault の owner でなくなる・無効化されると、そのトークンは使えなくなります。

        このトークンは今だけ表示します。控えてから閉じてください。

        心当たりのない端末があれば切ってから、パスワードを変えてください（変えると、ほかの端末はすべて切れます）。 サーバーを再起動すると、すべての端末のログインが切れます。

        自分の履歴
        時刻できごと誰がどこで備考

        直近3か月の、自分の操作・自分のアカウントに対して起きたこと・自分が owner の Vault でほかの人が行った操作です。 ほかの人の操作の接続元は表示しません（自分のアカウントへのログイン試行を除く）。
