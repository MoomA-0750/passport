🔐 Passport の設定

末尾の / は要りません。社内サーバーのホスト名か IP を入れてください。

入力欄のそばのメニュー

入力欄を選んだときに候補のメニューを出します。これを入れると、拡張は すべてのサイトで動けるようになります（Chrome の権限表示も 「すべてのサイトのデータの読み取りと変更」に変わります）。 サイトごとに許可したい場合は、ここを切ったまま、そのサイトを開いて ツールバーの Passport アイコンから「有効にする」を押してください。

ログインの保存を勧める

ログインの送信を見つけたときに「保存しますか」と出します。 本人が決めるまでの間だけ、入力された値を預かります（ディスクには残さず、 2分で期限切れ、ロックすると捨てます）。この機能は、入力欄のそばのメニューを 許可したサイトでだけ動きます。

    この拡張の ID

    —

    サーバーの passport.ini の [extension] allowedIds がこの ID を 許可している必要があります。既定値のままなら一致しているはずです。

    自己署名の証明書を使っている場合

    1. 先に普通のタブでサーバーを開き、警告画面で「詳細設定」→「アクセスする」を選ぶ
    2. 一度通しておくと、この拡張からの通信も届くようになります

    この拡張がしないこと

    • 許可していないサイトでは、拡張はまったく動きません
    • メニューから選ぶか、ポップアップのボタンを押したときだけ入力します
    • フォームを勝手に送信しません
    • パスワードを拡張側に保存しません。保持するのはログイン用のトークンだけで、 ブラウザを閉じると消えます
